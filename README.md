# Mohammed Malik — Portfolio

A bilingual (English / Arabic) personal portfolio and technical writing landing page built with React, Vite and Tailwind CSS.

## Run locally

1. Install Node.js (18+ recommended).
2. Open this folder in a terminal.
3. Run:

```bash
npm install
npm run dev
```

4. Open the local URL printed by Vite.

## Build for deployment

```bash
npm run build
```

The production website is generated in the `dist` folder. You can deploy it to GitHub Pages, Netlify or Vercel.

## Personalize before publishing

- Update the profile details and links in `src/App.jsx`.
- Replace the sample project descriptions with final project details and add direct repository / live-demo links.
- The writing section currently shows draft topic ideas, not published articles. Connect it to a blog or add article pages when ready.
- Add your own portrait if you want a personal photo in the hero section.
- Add a downloadable CV file and link if desired.

## Stack

- React 18
- Vite
- Tailwind CSS
- Lucide React
- Google Fonts: DM Sans, Manrope and Cairo
